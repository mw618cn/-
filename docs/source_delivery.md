# 源码交付说明

本仓库是可运行的24小时主配微协同韧性恢复研究原型，含源码、参数、测试、中文逐块导读及Word/公式生成脚本。演示参数由配置文件集中设置，可按真实数据替换。

仓库源码版没有预计算的结果和Word二进制文件。先运行算例，再运行文档构建脚本，即可生成模型、算例图和可编辑OMML公式；LaTeX公式源已经包含在equations目录。只生成代码说明书不需要先求解。

`downloads/tdm_source_code.zip` 是本次源码的独立快照，也可通过GitHub的Code → Download ZIP下载整个仓库。

完整模型、信息因果性、储能、能力分解和滚动约束测试见tests目录，运行方式见README。
