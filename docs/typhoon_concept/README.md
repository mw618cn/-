# 台风动态故障与恢复率优先：讨论示意

2026-11-09。本目录仅新增研究思路和图形表达示意，不改变ieee33_version或代码下载包的计算功能。

图decision_phase_concept使用任意解析函数：

`100 * [0.10*(SOC-0.55) - 0.035*(alpha-0.4) + 0.006*sin(2*pi*alpha)*cos(pi*(SOC-0.2)/0.7)]`

该函数用于画图，单位按百分点展示。它不是电网求解结果、机器学习预测或算例拟合，不能用于确定临界值、证明符号或选择控制策略。三维图和俯视图展示相同数据；零线由同一函数等值线生成。

拟采用的实际判据为D_R=当前启动分支的最大加权恢复率−当前等待分支的最大加权恢复率。先最大化加权恢复面积，再在恢复水平近似相同的方案间最小化成本和操作代价。若两分支最优恢复率区间分别为[L_s,U_s]、[L_w,U_w]，则D_R区间为[L_s−U_w,U_s−L_w]；跨零不等同于已证明平手。恢复近似平手后方可比较符合该恢复要求的次级成本。

正式相图可以使用主网剩余能力alpha×初始SOC，以台风条件作为分面；或在固定alpha下使用台风强度×SOC。每个格点均须重新优化两动作分支，同一比较使用同一资源和信息规则。改变台风强度时可共用随机数，但应重新计算风速驱动的故障，不能把已实现故障集合强行固定。

动态故障建议用移动风场驱动线路条件失效危险率，健康线路按p_new=1-exp(-lambda(v)*dt)发生新故障；已故障线路保持不可用，直到抢修完成。线路物理位置固定，故障集合随风灾扩大、随修复缩小。所有线路（包括常开联络线）均应按自身暴露程度受灾。累计脆弱性概率不能直接逐15分钟独立重抽。

当前33节点代码仍为两处已知位置初始故障、有限32接线菜单、有限抢修策略、成本优先MILP。本目录所述风场/动态多故障、通用带电森林、动态抢修和恢复率优先D判据尚未实施。标准IEEE33没有真实台风路径、地理坐标、道路和脆弱性数据，后续需要来源明确或标注为合成的数据；旧节点图的排版坐标不可当作真实地理坐标。
