# 全天能力与条件代价：实际计算示例

- capability_24h.png：24个整点截面，每个截面8个方向，共192次完整96时段LP投影。红线为同一次全24h可分解轨迹。
- conditional_cost_surface.png：7个启动辅助功率倍率×8个共同初始SOC，共56次完整24h条件LP。32点可行最优，24点在所固定的恢复方案下已证不可行。
- 灰色仅针对固定启动/开关/电池模式/抢修策略。它不证明所有离散恢复方案均不可行。
- 曲面数值为包含停电损失常数项的总期望费用，单位千元。没有用减去常数后的负目标冒充总费用。
- CSV保存全部实际采样点及同一参考轨迹。reference_context.json与reference_B11.npz保存参考模型参数和全场景解，可调用代码重建、校核并重新查询。

默认运行main.py将自动生成这两类图；网格和截面间隔可在Excel“运行设置”修改。旧Excel仍兼容。
