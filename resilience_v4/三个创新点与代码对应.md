# 三个研究点的实现链与研究验收

保留三个主线，不把台风、ADMM、排队/马尔可夫、神经网络再堆成新创新点。下述是拟研究贡献及实现范围，不是已证明“首次提出”或已完成期刊水平理论论证。

```mermaid
flowchart LR
  O[当前观测与继承状态] --> C[③ 因果任务树与承诺]
  C --> D[② 完整轨迹域与分解]
  D --> A[① 可实施证据与启动等待认证]
  A --> X[只执行15分钟首步]
  X --> O
  C --> A
```

## ① 条件可实施性约束下的启动—等待恢复价值认证

问题：能启动不等于当前启动值得；支撑会占用储能和通道，影响本地及后续关键服务。默认短限时两条可行计划差值不能直接当最优差值。

方法：在相同状态、天气/类型支持和有限派工规则类上分别求start/wait，结合后向条件管与完整网络见证保证能源可实施；已校核计划给L，完整整数松弛/信息松弛外界给U，按可能推翻首动作的竞争候选精化。只有有效区间越过声明容差才认证。

代码：bounds.py＋analysis.decide＋reachability.py；结果：每候选界来源、两动作SOC证据、D区间/分类与相图。模型未判、不可行和机组承诺后不适用分别处理。

研究还需：更广状态下的认证率/预算/误判检验，动作可达内外近似性质与敏感性。不能把给定计划的局部管说成全部状态的精确K(t)，不能强迫一定存在唯一临界点或D单调。

## ② 面向主配微恢复的多时段轨迹域协调与可分解保证

问题：每个P/Q截面可行，拼接成24h轨迹仍可能因跨期SOC、终端/后备或信息一致性失效；资源域非零也不等于TX通道可送达。

方法：每轮累计电量必要包络进入全局混合整数骨架；固定离散方案后，完整MGO可行见证列生成条件凸包。限制主问题实际消去微网内部变量列，以共同λ作用于所有微网/时段/样本；解后恢复完整控制并独立校核。快速连续更新仍在这个域内，当前界/真实历史同步保留。

代码：capability.py＋trajectory_domain.py＋rolling.py；结果：主问题变量数、消去列数、共同λ、完整分解残差、24h截面、首次不可延续前缀与最小跟踪修正。

研究还需：相同预算下集中完整模型、逐时截面松弛、全轨迹列法的可实施性/恢复误差/代价/耗时；独立方向检查保守性。一次拼接反例只证明该实例，不替代一般可分解定理。凸组合可实施性有明确固定模式/凸性/同信息条件；跨模式不能任意凸化。

既有杨明通文献已含多时段SOC和后向方法，不能写“现有方法都只考虑单时段”。本版仍有集中离散骨架，不是已经实现完整MPAR消元或ADMM分布式算法。

## ③ 信息揭示—任务承诺耦合的滚动抢修重构与启动调度

问题：检查时机决定何时能改变后续决策；正在执行的任务又限制可改范围。提前读未揭示类型会过于乐观，锁住所有未来计划则会错误禁止适应。

方法：故障报告后入队，检查完成才揭示；同历史动作一致；已经出发的行程/任务单独继承。及时目标选择用实际规则试排程，避免只展开很晚才检查的线路。事件/周期联合MILP、每15min连续域更新、只执行首步形成闭环。

代码：information.py＋analysis.simulate＋evidence.information_evidence；结果：有限支持后验、历史—动作表、揭示与维修分离、触发轨道、承诺状态和规则对照。

研究还需：信息能在真实启动窗口内到达并影响选择的算例；固定检查顺序、不利用类型等匹配消融；理想信息参考需保留因果策略可行集。当前信息松弛外界不是已执行的完美信息策略。L/H工时不同本身是参数，不是信息价值；任务非中断本身也是常见约束。

## 三点如何体现协同与韧性

TSO的启动需求/爬坡、DSO的通道/分区/抢修与MGO的本地服务/跨期输出通过PCC/TX及同一恢复目标共同约束。①选择当前资源用途，②保证全轨迹可实施，③随新信息与真实任务进度更新两者。

韧性由实际服务面积、关键失供电量、恢复时序及终端备用体现；费用是次级目标。joint与critical_first/nearest比较的是规则选择，双方仍有功率和拓扑协调；no_upward只隔离主配反送通路，不是完全无协同。

若允许协同的可行集包含禁止协同，最优恢复增益不应为负。可以研究当前强制启动的D为负，但不能把限时解或闭环策略劣化直接叫“可选协同本身有害”。

## 当前样例的规则类边界

默认joint只比较critical/information两个因果规则，nearest对照不在默认联合规则类中；三个策略集合没有完全包含关系。实际样例中nearest恢复面积更高是已保存结果，不为了显示优势修改曲线。可将information.crew_policies改成critical,information,nearest，并将max_policy_candidates改为3，研究含就近规则的扩大类；必须统一重新运行，不能把旧样例改标签当新结果。即使包含该规则，有限预算及预测误差下的实际闭环轨迹也不保证逐样本排序。
