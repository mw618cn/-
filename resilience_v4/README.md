# R4：可认证首动作与完整轨迹域协调

**只运行main.py，默认只维护参数数据.xlsx。** 完整解压到新目录，保留R3用于比较；不要少量覆盖旧版文件。

```bash
python -m pip install -r requirements.txt
python main.py
```

Python 3.11—3.12，使用HiGHS，无商业求解器许可证要求。参数Excel请用Excel/WPS打开；IDE的“No loader”只表示没有预览插件。

## 本版真正改变了什么

1. D上界不再只依赖短限时MIP。增加完整LP松弛和放松信息一致性的分场景外界，使用含盒余项的拉格朗日数值证书。只在可能改变首动作的候选上求界，记录预算、来源、间隙和未判。
2. 多时段能力域进入实际协调。固定离散方案后，MGO完整轨迹列替代微网内部变量进入限制主问题，求共同lambda；随后恢复指令。每次快速连续更新仍保留这个域及真实已执行前缀。
3. 类型目标按因果规则试排程中的预计检查时间选择，避免仅挑很晚才可检查的高权重线路。保存历史等价类、后验、动作、实体承诺和MILP触发原因。
4. 拼接反例新增首次不可延续前缀和最小跟踪修正。稀疏截面画采样点/轮廓，D图画实际点与认证类别，不补造临界曲面。

仍是**集中MILP离散骨架＋固定骨架后的连续轨迹列主问题**。没有实现ADMM、一般POMDP/VRP全局最优、所有离散模式的完整投影或样本外安全证明。

## 默认运行与计算时间

默认24h/96个15min时段、33配网节点＋T0/T1、3个MGO；K=2个当前未知类型，与1条预测天气路径交叉，共4个类型样本。K=3为8类；再增加天气路径会进一步扩大模型。

默认运行joint、critical_first、nearest三种策略。`run_comparisons=否`可先只运行joint；`run_coordination_baseline=是`再加禁止TX反送对照。各对照共用实际风灾，仍各自逐步观测、继承真实SOC和任务，不以一次预测替代执行。

本模型包含十万量级变量、候选LP、外界、主问题、分解和相图查询。单次MIP的2秒**不是全程序2秒**。外界有独立预算；“认证”不保证在任意预算下成功。计算期间会打印候选、外界、域协调和滚动时刻。先检查运行日志，再等待完整结束。

需要先检验完整96步时，可把“运行设置”的`run_comparisons`、`compute_phase_map`、`compute_capability`临时改为否；时间网格和物理模型不缩短。论文实验应打开对照/域/相图并提高精度，用多个seed和匹配消融。

## 原版宋体

所有交付图强制原版宋体，不使用替代字体。Windows自动查找`C:\Windows\Fonts\simsun.ttc`；也可在算法设置`plots.font_file`填写路径，或使用环境变量`TDM_SIMSUN_PATH`。

云端尚缺完整原版宋体，所以没有声称已完成宋体预览。数值完成后会保留JSON/Excel，并明确写出缺字体说明。Windows可用系统宋体重画包内数值示例：

```bash
python main.py --redraw 示例结果_24小时
```

重画自己的运行则换成实际`results/运行_...`目录。无需重算模型。R3结果请使用R3程序，R4对新结果执行严格来源检查。每张图输出PNG/PDF/SVG，明确88.9mm单栏或180mm双栏，最小字号6.5pt；总图注在论文排版中添加。代码包不分发字体。

## 关于信息窗口算例

可在同一表把`generator.earliest_start_hour`设为4，表示机组前4h确有准备/检修限制，再研究2—3h内获得的信息如何影响4h后的启动选择；这是需工程解释的合成情景，不是为了增加D点随意推迟启动。程序继承实际执行到首个可比较时刻的状态再做条件相图，不重置SOC/历史。

默认机组0h可启动，若实际0h启动，后面D不再适用是正常承诺逻辑。不得将已经在线的机组重置为“未启动”来凑D曲线。

当前附带样例的三种24h策略已完整运行；其中就近规则实际恢复面积较高，不预设联合类优势。默认joint规则类不包含nearest，扩大类的参数位置和解释见三个创新点文档。额外禁止反送24h对照本次未完成，未放入其部分曲线；运行选项和相应平衡排除测试已保留。
