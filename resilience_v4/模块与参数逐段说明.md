# 参数→场景与信息→模型→认证→协调→首步执行→出图

main.py是唯一必需运行入口；其他文件由它调用。默认一份Excel，其他示例配置是可选实验条件，不会自动叠加读取。

## 1. 数据与网络

**data.py**：rows读第2行字段、第4行起数据；load_parameters组装接线/负荷/PV/台风/机组等；validate_config校验时间、SOC、概率、窗口和算法设置；save_json统一numpy/非有限值；write_workbook只导出已计算证据。

**network.py**：prepare建立节点/PCC/TX及邻接映射，生成恢复目标分母；静态repair_priority仅用于候选派工评分，不等于每一时刻真实边际恢复收益。

| 表 | 主要内容 |
|---|---|
| 基础参数 | 时域、步长、α、电压、操作预算、机组、队伍、主/次求解预算 |
| 节点负荷/地理坐标 | 关键/一般基值、protected、示意坐标与独立合成km坐标 |
| 线路参数 | RX/容量、开关和暴露性、首损参数、检查/轻重修复工时；plot_route仅画图 |
| 微网参数 | PV/DG/BESS、逆变器、效率、SOC及费用 |
| 24小时曲线 | N行倍率×基值；不能把MW绝对值误填为倍率再乘装机 |
| 台风路径/启动曲线 | 路径覆盖灾前历史到终点；辅机MW轮廓按Δt完整排列，不跳峰值 |
| 运行设置 | 策略、天气路径数、域/相图、对照、输出路径 |
| 算法与绘图设置 | K、及时目标、域列、外界方法/预算、精化、字体与列宽 |
| 数据来源与标定 | 标准测试数据与待校准合成输入分别说明 |

节点、线路、微网数量从表读，但仍要求首节点T0、唯一命名TX接口、一台待启动机组、一支队伍。改数量须补全全部曲线/接线，不是自动生成任意规模系统。

## 2. 环境与信息

**weather.py**：wind_field→hazard/make_world实际样本；forecast只用state独立预测。实际隐藏类型只在analysis.advance_crew检查完成后读取，不把world未来给调度器。

**information.py**：make_crew_plan在单个因果规则下推进每条预测路径；报告后入队，检查完成后才按类型分支；trace记录实体任务，histories记录信息，二者分别检验。expand_hidden_types先试排程估计各未知目标揭示时间，再展开K个类型与天气路径的笛卡尔积；其余未知重伤上界。

**repair_model.py**：距离/速度/绕行系数与Δt取整；部分自由排序工具保留兼容，默认R4由information.py提供完整因果作业树。没有排队/马尔可夫服务模型或真实道路GIS。

## 3. 全局模型和首动作界

**power_model.py**：ModelBuilder命名稀疏变量/行；build_model按任务可用性、网格、带电森林、P/Q/SOC、启动轮廓、操作约束、包络/后备集、NA组装；safe_seed构造充/放/混合计划；optimize恢复优先再降成本；validate独立检查矩阵、整数、PQ、SOC、源/森林、任务与信息。

**bounds.py**：class_bounds负责候选并集L/U；finite_box推导PCC有效界；lagrangian_lower保留数值余项；relaxation_bound求完整整数松弛；scenario_relaxation_bound检测NA外的分块结构后形成信息松弛外界；apply_bound检查上下界冲突；model_fingerprint防止跨问题缓存；reuse_cached_bounds保留同一问题已有MIP/LP有效界和可行下界。

LP外界只放松约束。固定整数LP、轨迹列主问题或启发式可行解均不能冒充外界。源文件中的source/scope字段记录这一差别。

## 4. 域与后向

**capability.py**：interface_envelopes更新累计PCC电量必要界并进入全局模型；build_resource_model保留完整剩余时域/样本、固定模式和信息条件，用于轨迹列/投影/分解。

**reachability.py**：delta_interval解析消元单步LP；island_reserve_tube从终端倒推岛内服务后备；certify_commands在给定PCC/服务/模式/信息树下交子分支、求前驱，只对兼容后缀出证。

**trajectory_domain.py**：index_map把局部变量与全局内部列对应；build_columns保留参考列并查询累计输出、启动支撑、充电、本地服务等方向；restricted_master消去内部列，加入全时域共同lambda与被消去列的当前界；solve_with_domain恢复完整指令并核查；coordinate执行两级连续协调。约束保留，不把消元误当删除物理约束。

## 5. 滚动与方法证据

**analysis.py**：decide对start/wait及规则类建模、给上下界、按需精化、运行域协调和后向校核；simulate推进真实环境；compute_capability显示完整轨迹域/分解；phase_map对相同状态和随机数作反事实α/SOC扫描，未判点才追加精度。

**rolling.py**：固定已经执行的真实前缀/SOC；对兼容预测支持重解剩余连续域主问题，更新当前PV上限和后备管。旧域不能实施则转联合重建。未来计划暂时固定是数值加速，不是全部未来任务都已锁定。

**evidence.py**：information_evidence保存观测等价类、有限支持后验与同组控制差；splice_diagnostic计算首次不可延续前缀和保持硬约束的最小跟踪修正。证据在求解层生成，绘图不补造。

## 6. 出图与质量

**diagnostics.py**：从实际供电数组独立重算R/EENS、PQ、SOC，检查故障线未闭合/充放互斥/96步/固定终点/域使用；模型最优性未证与首动作已认证分别统计。

**plot_style.py**：强制原版宋体及字符覆盖，逐Text绑定同一字体文件；figure(height_in,width)明确英寸与单/双栏；线型/标记与颜色并用。

**plots.py**：只读数值证据；图07显示24小时范围与离散截面轮廓，08只画格点与认证，11/12/14/15分别承载信息、后向、跨期失效和真实在线域协调。无数据不补造曲线；旧清单生成图清理后再输出。

## 7. 最常修改的设置

| 设置 | 实际作用 |
|---|---|
| information.max_hidden_targets | K；样本数约天气路径×2^K，不是全部线路联合分布已精确展开 |
| information.target_selection | timely试排程及时性或priority静态权重，便于匹配消融 |
| domain.coordination/max_columns | 是否真正使用轨迹列主问题及列上限；关掉时回到集中连续扩展模型 |
| solver.use_relaxation_bounds | 是否求额外外界；关掉仍保留MIP/普适界，可能未判 |
| solver.bound_method | scenario_then_full或full；前者先用可分信息松弛外界 |
| solver.bound_lp_seconds/decision_bound_seconds | 单次界与每轮界总预算，独立于MIP时间；已认证可提前停止 |
| solver.close_certified_interval | 认证后补齐尚缺有效外界的候选，便于报告两端；不保证完整最优值闭合 |
| solver.decision_refinement_rounds/seconds | 同一问题追加MIP，保留可行解与证书 |
| analysis.phase_refinement_rounds/seconds | 只对未判格追加精度；复用相同矩阵缓存，避免重复求同一外界 |
| analysis.phase_extra_bound_seconds | 相图精化阶段再求界的额外预算，0则只复用有效界并改善可行解 |
| generator.earliest_start_hour | 真实最早准备完成时刻，默认0；需工程理由，不能为增加D点任意设置 |
| control.full_milp_each_step/replan_hours | 每步联合重算或周期+事件联合，连续控制始终每15min更新 |
| reachability.enforce_island_reserve | 可关闭额外岛内保供到终点约束，改变可行域，需匹配消融 |
| plots.font_file/single_width_mm/width_mm | 宋体路径、单/双栏宽；不改变物理解 |

HiGHS限时解在不同CPU/并发负载下可能不同，seed一致不保证限时MIP逐位一致。应比较保存见证、有效界、物理残差和预算，不把一条曲线的微小差距直接称显著收益。
