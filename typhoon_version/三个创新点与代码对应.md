# 三个创新点与 r2 实现的对应

## ① 启动／等待决策边界

比较同一状态、同一信息和预测样本下“当前启动”和“当前等待”的全过程加权恢复面积。等待保留未来启动选项；两分支各自优化后续作业、拓扑及资源。D_R界为 [L_start-U_wait, U_start-L_wait]。有限预算不能分离界时，执行已取得的可行计划，但保留未判。

r2修复：充电与放电候选均评估，增设混合模式和模式邻域搜索；保存候选、完整MILP改善量及恢复率间隙。SOC轴不能再因未评估放电候选而机械失效。代码入口为 analysis.decide/phase_map 和 power_model.optimize；对应图06/08。

## ② 多时段可分解支撑能力

每次滚动由真实SOC、剩余预测PV及本地负荷生成跨期累计净输出能量包络；显式PCC轨迹将微网内部约束与DSO网络连接。包络是必要条件，全局MILP保留内部状态和精确充放电互斥，从而保证取得的指令有内部实现。

这是能力域的扩展形式及能量包络嵌入，不等同于完整高维投影压缩。capability.interface_envelopes 负责更新；power_model.build_model 将包络及PCC平衡实际加入优化。SOC/网络/信息更新后再建模，形成运行闭环。

出图另用 capability.build_resource_model：移除TSO/DSO网络，仅保留微网96时段SOC、本地负荷、逆变器、终端储备及同信息控制；给定充放电模式后查询资源P/Q域。analysis.compute_capability 对整条逐微网PCC轨迹做本地分解校核。网络可送范围单独计算，避免把通道隔离误当成资源能力为零。对应图07和滚动能力包络表。

## ③ 信息驱动的抢修—重构—启动协同

风速驱动新故障，当前已报告任务进入模型；未知损伤先按工时上界规划，真实巡检揭示轻重后重新优化。行程、安全风速暂停、执行承诺与操作预算共同限制抢修和重构；供电与启动价值影响可选作业的选择。

r2在原统一MILP中增加不同日程候选，不以候选代替优化。对照区分“固定重要负荷抢修规则”和“禁止向上支撑”，分别检验作业协调与上送权限。天气等待单独出图。代码为 repair_model、power_model、analysis.simulate；对应图02/05/09/10。

当前预测内已报告作业日程跨场景共用，尚未报告任务在报告后加入，不宣称完整内生信息多阶段随机优化或最优信息价值。

## 因果闭环与韧性

当前观测 → 更新故障、SOC和接口能量包络 → 在主配微物理约束下比较启停并联合选择作业及开关 → 执行15分钟 → 更新真实信息和状态 → 再优化。

韧性以全过程加权恢复面积及EENS衡量，关键负荷单独统计；策略差值按相同灾害和资源计算。恢复下降可来自新增故障，不能强制曲线单调。

集中式MILP是当前求解器；ADMM尚未实现。三个研究点的最终创新性仍需文献比较、严格域性质及多样本消融支撑，代码修复不等于已经证明论文创新成立。
