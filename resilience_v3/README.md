# R3：主配微协同韧性恢复，可独立运行的完整版本

用户入口仍然只有 **main.py + 参数数据.xlsx**。其他文件是主程序调用的模型模块，不需要逐个运行。建议 Python 3.11—3.12 的独立环境。

本版围绕原来的三个研究点：①启动/等待的恢复价值判据；②全时域可实施能力表示；③巡检信息、任务承诺与抢修—重构—启动的滚动协同。台风输入不另列创新点。**当前实现为集中MILP/LP及有限因果作业策略类，没有实现ADMM，也不宣称一般POMDP全局最优。**

## 1. 安装和运行

完整解压到新的文件夹，不覆盖旧版本。第一次在该文件夹运行：

```bash
python -m pip install -r requirements.txt
python main.py
```

也可以在 PyCharm 中选择本文件夹的 main.py 运行。Excel请用系统 Microsoft Excel/WPS 打开；IDE提示“No loader”表示IDE没有电子表格预览插件，不代表工作簿损坏。编辑后先保存Excel，再重新运行程序。

程序依次读取表格、生成实际风灾、逐步观测和调度、计算域与相图、保存Excel/JSON、生成图形。一次完整24h计算含大量LP和多次MILP，**solver.primary_seconds只限制单次MILP阶段，不是整次程序的耗时**，候选构造、校核、后向递推、能力域和相图均另外耗时。

默认先运行 joint 主策略，生成完整96步轨迹、24个小时截面及3×3 D采样网格。需要策略对照时，在“运行设置”把 `run_comparisons` 改为“是”；`policies` 可填 `joint,critical_first,nearest`。把 `run_coordination_baseline` 改为“是”，还会运行禁止向主网反送的对照。第09图只有取得至少两组真实结果才会生成。

## 2. 原版宋体是硬要求

Windows自动查找 `C:\Windows\Fonts\simsun.ttc`。也可以在“算法与绘图设置”的 `plots.font_file` 填完整路径，或设置环境变量 `TDM_SIMSUN_PATH`。程序会检查字体家族及图中文字形，缺字/缺宋体时不替换为思源宋体，也不输出冒充宋体的预览。字体不包含在代码包中。

本次云端未获得完整原版宋体文件，所以附带的是数值示例，**没有声称已经完成宋体预览**。Windows中可直接用系统宋体重画附带示例，无需重新优化：

```bash
python main.py --redraw 示例结果_24小时
```

自己的运行结果重画时，把最后一项换成 `results/运行_...` 的实际文件夹。宋体只影响绘图，缺字体时数值结果仍会保存，并留下 `绘图未完成说明.txt`。

## 4. 结果在哪里，哪些参数先改

每次创建独立 `results/运行_年月日_时分秒_微秒`，复制本次Excel；保存实际环境、每轮决策、96步实际轨迹、控制器记录、能力域、求解界、质量报告及结果汇总.xlsx。`world.json` 供环境推进和事后统计使用，优化器不读取实际未来的损伤类型。

先替换具有实验依据的台风路径、线路危险率/脆弱性、GIS、行程和工时，再校准微网资源、机组启动曲线与重要负荷。演示的风场、脆弱性、道路、修复时间及机组曲线是**合成数据**。MATPOWER33节点的接线及原始RX/PQ可追溯，不代表气象和地理坐标也来自标准系统。

默认D相图求解预算很短，可能全部显示“未判”。提高 `solver.phase_seconds`、`solver.primary_seconds`、`solver.decision_refinement_seconds`，缩小已论证的策略类或改进模型界，才有可能获得更窄判据；增加网格密度本身不会提高每点最优性精度。程序不保证临界边界必然存在或D单调。

## 5. 可验证范围

实际96步数值已经检查首步执行、历史继承、功率/SOC、故障隔离、整轨迹分解。有限天气样本、K个未知类型和有限派工规则是明确的计算边界。未建立频率、电磁暂态、同期涌流、通信故障、任意道路阻断、复发故障或一般多队伍最优路径模型。本版本不把这些未实现内容写成已完成创新。
