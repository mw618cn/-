# 各图的物理含义、表达改动及文献借鉴

所有时序计算为24h/96个15min时段。域默认每小时画一个截面，但每个支持点求解仍保留全部96时段。使用原版宋体、180mm图宽、常规8pt文字、600dpi PNG与PDF/SVG；IEEE排版风格不等于已按某一期刊最终模板录用排版。

## 逐图阅读

| 图号 | 画什么 | 应当读出的结论；不能据此推出什么 |
|---|---|---|
| 00 节点接线与开关位置 | T0/T1、D1—D33、MGO、可控开关、初始故障 | 明确三层在哪、哪些支路可控；是电气示意图，不是实测GIS |
| 01 台风路径/风速/故障概率 | 地理路径与样本故障点、代表线风速/故障时刻、单区间条件概率、累计首损计数均值与实际样本 | 把风险输入、随机实现和统计期望分开；不再把一张模糊风速热图当故障概率证明 |
| 02 故障/修复/投入时序 | 每条相关线路一行：故障阴影、修复圆点、主动合闸三角及真实连续带电区段 | 故障≠待合闸≠带电；已修不必投入。带电片段不能跨越中间故障连接 |
| 02b 主动开关事件 | 每次主动分合闸的时间/线路 | 看何时重构、哪些操作；不含保护跳闸/固定接线恢复 |
| 03 主配微功率与SOC | TX上送、辅机、机组出力、每微网净PCC和真实SOC | 资源如何跨三层支撑、何时储能被消耗及回充；不是资源毛发电都能上送 |
| 04 韧性 | 需求/已供、关键/加权恢复率、关键/一般EENS、带电节点电压范围 | 反映整个恢复过程而不是单个末时刻指标；不把失电节点0电压混入合规电压统计 |
| 05 检查与维修甘特图 | 分线路行程、有效检查、有效维修、天气等待；菱形为实际获知L/H | 清楚分离信息到达与物理修复，已获知/已修数量分开；空白表示该行未作业，不代表队伍正在该行空转 |
| 06 D与启动承诺 | 只有真正存在自由当前启动选择时的D点及上下界；下栏显示未启动/辅机/在线 | 一点可能就是完整正确图。机组已启动后不伪造后续自由决策；跨零区间不能称已证明启动更优 |
| 07 全时域资源域和分解 | 24个P/Q截面、同一完整参考轨迹、逐微网分解能量 | 切片来自完整模型，分解是一条完整策略的证据；截面不是可以任意拼接的静态集合 |
| 08 D采样网格与证据分类 | 左为实际求得计划差值的逐格数字，右为界认证/未判 | 默认不称其光滑曲面，不插值涂出临界区；数据表含每格上下界及超时信息 |
| 08b 可选D线框 | 同一采样点的三维散点和分段线框 | 只辅助看趋势，无平滑插值或连续临界面证明；需要开启plots.phase_surface |
| 09 实际策略对照 | 同一风灾下各规则/反送设置的真实恢复轨迹和EENS | 只在确实运行对照后生成，不强行拉开曲线；规则基线仍有电力优化 |
| 10 服务状态拓扑快照 | 绿全部恢复、橙部分、灰失电、白带电但未恢复、淡蓝无本地负荷；故障线有叉、MGO有菱形 | 把供电比例与节点带电分开，四色/符号加强区分；不能靠颜色推断暂态可行 |
| 11 检查触发信息分组 | 初始候选预测树各时刻的观测组和类型揭示菱形 | 同一列同色代表同信息、组内动作必须相同；不是实际未来信息“提前知道”，颜色跨列没有身份继承含义 |
| 12 条件后向可达管 | 初始候选的SOC可达上下界、岛内安全后备下界、同一候选SOC、当前状态 | 是从终端向前驱递推，不是把实际执行轨迹硬塞进初始预测管；不是全系统精确动作可达域 |
| 13 首步执行与固定终点 | 已执行前缀、剩余计划、当前15min动作；下栏96步MILP/LP更新点 | 研究终点固定24h；每一步求解/校核，但不承诺每一步都重新优化全部离散变量 |
| 14 完整轨迹与拼接检验 | 可分解参考轨迹与逐时挑点的拼接轨迹，标实际LP判定 | 直观显示“逐时可行不等于全时域可实施”；若某个样本拼接恰好可行也如实报告，不编造失败 |

## 对用户旧图问题的具体处理

01图改为四面板，分开风险概率与样本；02改为事件甘特图和操作事件图；05改为行程/检查/维修/天气等待及信息菱形；06改为自由决策点的区间图与承诺阶段；08默认用有数字的网格和认证类别，不把少量格点画成光滑曲面；10采用离散服务颜色和符号。新增11—14图承载信息因果、真正后向递推、滚动执行和轨迹拼接证据。所有图仍须经过原版宋体环境实际渲染检查。

## 怎样获得论文可用的结果证据

先校准数据和机组尺度，再固定场景/信息/求解预算做joint、critical_first、nearest、no_upward对照，另设计有/无后向储备、静态逐时域、延后信息揭示等匹配消融。增加台风seed做统计；对D临界区增加求解预算而非只做漂亮插值。图是证据呈现，不替代可行性、最优性或方法新颖性的证明。
